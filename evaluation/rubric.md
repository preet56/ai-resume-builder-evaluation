# Evaluation Rubric (1–5 Scale)

All team members must use this rubric consistently when scoring generated resumes.

## Scoring Criteria

### 1. Relevance to Job Description

- **5** = Strongly aligned with job requirements, skills, and responsibilities
- **4** = Mostly aligned with minor gaps
- **3** = Moderately aligned, some missing relevance
- **2** = Weak alignment with job description
- **1** = Not relevant to the job

---

### 2. Clarity and Professionalism

- **5** = Very clear, concise, and professional language
- **4** = Clear with minor wording issues
- **3** = Understandable but somewhat awkward or wordy
- **2** = Difficult to read or unprofessional tone
- **1** = Confusing or poorly written

---

### 3. Resume Structure and Formatting

- **5** = Well-structured with proper sections (Education, Skills, Experience)
- **4** = Mostly structured with minor issues
- **3** = Acceptable structure but inconsistent formatting
- **2** = Poor structure, missing sections
- **1** = No clear structure

---

### 4. ATS Keyword Alignment

- **5** = Strong use of relevant keywords from job description
- **4** = Good keyword usage with minor gaps
- **3** = Some keywords present
- **2** = Few relevant keywords
- **1** = No meaningful keyword usage

---

### 5. Factual Consistency / Hallucination

- **5** = No hallucinations or fabricated information
- **4** = Very minor questionable details
- **3** = Some inconsistencies but mostly reasonable
- **2** = Noticeable fabricated or misleading content
- **1** = Significant hallucinations or false information

---

## Important Notes

- Be consistent across all evaluations
- Do not rush scoring
- If unsure between two scores, choose the lower one for consistency
- Each resume should ideally be evaluated by more than one team member
